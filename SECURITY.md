# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest on `trunk` | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

**Do not open a public issue.**

Instead, email the maintainer directly or use GitHub's private vulnerability reporting feature under the Security tab of this repository.

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

You can expect an initial response within 72 hours.
