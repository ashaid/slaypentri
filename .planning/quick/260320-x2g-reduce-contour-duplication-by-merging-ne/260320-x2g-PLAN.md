<objective>
Add a contour deduplication step to the image pipeline that merges contours which are close and roughly parallel, keeping only one representative contour per visual line.

Purpose: Thick lines in input images produce multiple nearby parallel contours from Canny edge detection (one for each side of the line). This doubles stroke count and causes visible double-drawing artifacts. Merging near-duplicates reduces both painting time and visual noise.

Output: Updated painter.py with deduplicate_contours() function, new config parameter, and tests.
</objective>

    **Algorithm for deduplicate_contours(contours, merge_distance_px):**

    This function operates in PIXEL space (before normalization), receiving the list of simplified+filtered OpenCV contours.

    1. If merge_distance_px <= 0, return contours unchanged (feature disabled).
    2. For each contour, compute its centroid and average direction vector (PCA or simple endpoint-based angle).
    3. Build a "keep" boolean array, all True initially.
    4. For each pair (i, j) where both are still kept:
       - Compute mean Hausdorff-like distance: for a sample of points on contour i, compute min distance to contour j, take the mean. This is cheaper than full Hausdorff and sufficient for near-parallel detection.
       - If mean distance < merge_distance_px, mark the shorter contour (by arc length) as not-kept.
    5. Return only kept contours.

    **Optimization note:** Use cv2.pointPolygonTest or manual vectorized distance. For typical contour counts (<1000), O(n^2) pair comparison with sampled point distances is fine. Sample up to 10 evenly-spaced points per contour for distance checks to keep it fast.

    **Config addition:**
    - Add `merge_distance_px: 5` to `edge_detection` section in DEFAULT_CONFIG_CONTENT and _DEFAULTS dict.
    - Add YAML comment: `# Merge distance in pixels (0 = disabled). Contours closer than this are merged, keeping the longest.`

    **Pipeline wiring in run_image_pipeline:**
    Insert the deduplication call between the arc-length filter and normalization steps (after `filtered = [...]`, before `state.contours_normalized = [...]`):
    ```
    merge_dist = state.config["edge_detection"]["merge_distance_px"]
    deduped = deduplicate_contours(filtered, merge_dist)
    ```
    Update the verbose debug print to show dedup count: `"after filter: {len(filtered)}, after dedup: {len(deduped)}"`.
    Use `deduped` instead of `filtered` for the normalization step.
